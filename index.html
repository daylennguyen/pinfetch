Pinfetch

Download full-quality images from a public Pinterest profile or board. Profile URLs pull Unorganized Ideas (boardless saves at the bottom of a profile). Board URLs pull a specific folder, such as …/stuff-to-buy/.

Works with profile roots, /username/_saved/, and board paths like /username/board-name/.

How it works

  • Quick scan uses Pinterest’s public widget API; large boards may need the bookmarklet export.
  • Unorganized Ideas use the hidden _quick_saves board behind profile saves.
  • Images are packaged in the browser with JSZip; blocked CDN fetches fall back to a CORS-safe proxy.
  • Only public boards work from GitHub Pages.
